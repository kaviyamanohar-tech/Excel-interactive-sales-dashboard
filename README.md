# Interactive Bike Sales Dashboard Using Excel

## 📌 Project Overview
This project focuses on cleaning and analyzing bike sales data using Microsoft Excel. An interactive dashboard was developed to explore customer demographics and bike purchasing behaviour.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

## 🧹 Data Preparation
- Cleaned and organized the raw bike buyers dataset.
- Prepared the data for analysis.
- Created Pivot Tables to summarize customer information.

## 📊 Dashboard Features
- **Average Income Analysis:** Compared customer income by gender and bike purchase status.
- **Customer Age Analysis:** Explored bike purchasing patterns across different age groups.
- **Commute Distance Analysis:** Examined bike purchases based on customer commute distance.
- **Interactive Filters:** Used slicers for marital status, region, and education.

## 📁 Project Files
- `Bike_Sales_Dashboard.xlsx` – Excel workbook containing the interactive dashboard.
- `dashboard_preview.png` – Dashboard screenshot.

## 🎯 Key Learning Outcomes
- Practised data cleaning and preparation using Excel.
- Developed interactive dashboards using Pivot Tables and Charts.
- Explored customer purchasing patterns through data visualization.
- Improved data analysis and dashboard design skills.

## 🏁 Conclusion
This project provided hands-on experience in transforming raw data into meaningful insights through data cleaning, analysis, and interactive visualization using Microsoft Excel.
